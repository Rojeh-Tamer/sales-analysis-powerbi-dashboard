# 📊 SALES ANALYSIS POWER BI DASHBOARD

### An interactive Power BI dashboard designed to evaluate sales performance, regional growth trends, and product metrics using custom UI background layouts and DAX modeling.

---

# 📌 KEY FEATURES

### • Interactive Sales Analytics: Dynamic filtering by region, date range, product categories, and customer segments.
### • Custom UI/UX Canvas Layout: Built with custom canvas layouts (`sales_dashboard_bg_1280x720.png`) and dedicated branding icons for a polished executive view.
### • Advanced DAX Calculations: Time-intelligence functions, YoY sales growth, total revenue metrics, and profit margins.
### • Visual Data Storytelling: Clear chart formatting optimized for fast business decisions.

---

# 🛠️ BUILT WITH

### • Business Intelligence: Microsoft Power BI Desktop (`.pbix`)
### • Data Source: Microsoft Excel (`Sales Analysis Report.xlsx`)
### • UI/UX Design: Custom PNG layouts & iconography
